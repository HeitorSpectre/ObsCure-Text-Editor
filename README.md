# ObsCure-Text-Editor
ObsCure Text Editor is a tool for editing text from this franchise, designed for Nintendo Wii, PC, PS2, PS3 and Xbox 360.

## SUPPORTED GAMES
- Obscure 1
- Obscure 2
- Final Exam
